# ROM数据读口隔离 v69

v68b双口逻辑ROM实验已拒绝，不作基线。本候选回到v67，仅分开两个不可写ROM视图：取指数组保留block_rom，数据数组加载同一INIT_FILE并将同步数据输出标注为logic。1024×64地址空间、两个端口独立使能、同步一拍响应与输出保持不变，不修改LSU或增加等待周期。

组件实际映射为取指1个DRM18K、数据2LUT/2FF，实际综合VM双口全地址/保持5124检查通过，读数据破坏负例检出。资源只对应本次冻结启动镜像。取指工具端口由原B转为A，仅保留资源类型，不声称物理结构/布局等价。

完整CPU回归使用v65CPU、v67存储控制和v69ROM：CoreMark1221907周期、1448448条观察WB、4.091964/MHz；镜像、完整WB/store和profile与v67完全相同。该分数为-O2 RTL短测，非官方或板测。

整核原生映射已核验：CPU-only 9709 LUT/4906 FF/752个已包含RAM-LUT/4 APM/0 DRM，比v67增加128 LUT、减少2 FF。ROM夹具另计2 LUT/2 FF/1 DRM18K。68项原生输出和122项仿真输出哈希已核对。selector检查PASS，recovery顶层HOLD仍仅为连通性诊断。独立启动复审无阻塞，新物理包已完成唯一一次原100MHz约束实验；默认RTL、主工程集成及板卡不变。100MHz尚未通过。

证据：[dualissue_rom_split.json](../verification/cpu/dualissue_rom_split.json)。

## 实际物理终态

TIMING_FAIL，PDS native退出0，验收runner记录2。冻结输入及394项输出哈希、五个新阶段成功标记、performance slack一致性均通过核验。

| Minimum pulse width | +3.655 | +4.202 |

Slow setup 9个违例端点，TNS -1.361ns。相同10ns约束下，v67为-0.218ns，本轮弱0.057ns；新映射/布局不能视为固定布局对比。最佳v57 -0.009ns仍未通过。该ROM分离候选未采用为默认或最佳版本，不重复跑种子。

实际9条违例中8条为乘法APM结果→E1转发选择→32位零判断→零分支不跳转配对许可→FIFO头更新；另1条为队头→A路ALU（-0.006ns）。最差10级、逻辑2.970ns、布线6.965ns，乘法器Tco为1.610ns，配对控制中有158负载，后续FIFO控制116负载。这里是配对/出队控制，不能仅按信号名归结为分支恢复。

后续先审查MUL/ALU零标志在宽数据选择前计算的可行性，保留未知选择时逐位合并语义；这只是待验证假设。若映射继续串接零判断/宽队头控制或扩大扇出，则不进入下一次PNR。ROM方向两次物理实验已完成，停止叠加ROM属性。没有新增等待周期或放宽约束。

独立终态复核确认394输出、30输入哈希一致，无证据阻断项。优先候选进一步收窄为现有无符号16×16早期乘法的同步零侧带：二态下完整32位乘积为零等价于任一低16位操作数为零；该性质不得用于任意截断32×32乘法，也不能直接覆盖0×X的四态行为。测试先覆盖采样、连续hold、复位、有效标记、两路转发优先级和BEQ/BNE x0，再决定是否进入映射。此候选尚未实施。
