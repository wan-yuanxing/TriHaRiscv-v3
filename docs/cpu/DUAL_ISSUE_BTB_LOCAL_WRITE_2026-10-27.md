# BTB 块内训练写许可 v76

基线v75。实际最差为训练索引→8块tag宽选择→tag比较→target WE，601扇出/9.163ns布线。每个32行块直接比较本块训练tag与写入tag，并读取本块valid，再生成本块target WE。保持write_i && (taken_i || !write_hit)策略、原写地址延迟结构、表容量、所有状态和周期不变。

已知3位block索引用局部许可；未知索引保留原完整四态表达式。不能删掉非taken命中保留旧target的规则。代价可能是复制比较器/valid读选择，须检查真实映射和资源，不能依据RTL层数直接PNR。

门槛：父版全部输出/512valid/16块WE时钟对照，全部行填充、命中不跳转保留、别名替换、X/Z与复位/失效重叠；旧共享write_target污染红测、新本地通路正测及真实WE损坏负例；独立BTB规格oracle；完整CoreMark及WB/store/profile；native核对实际WE锥，再独立审查。B恢复CE违例仍独立存在，未宣称整核收敛。

父版全输出/valid/16块WE正常159168项、污染正测159169项通过；覆盖16384组独立四态block/更新控制×4种bank状态。独立BTB规格oracle10066项通过。当前TB版本重新执行旧版污染红测与实际WE损坏负例，均检出；旧初测记录保留，不与增强TB哈希混用。

完整SRAM仍1221907周期/1448448观测WB、短估算4.0919644457/MHz，measurement/profile、镜像、WB/store与v75相同。原生三阶段通过，CPU核9755LUT/4977FF/752已含RAM-LUT/4APM/0DRM，比v75+228LUT/+2FF，严格u_cpu9754LUT。

实际256 target RAM WE均只依赖本块21tag/32valid及训练控制；624 RAM实际WADDR均连接对应最终延迟边界，80个两级写地址边界保留。跨块tag依赖注入使16个WE拒绝，绕过第二级实际地址连接负例也拒绝。独立审查确认当前网表证据。连接/边界检查不等于物理延迟或hold通过。
