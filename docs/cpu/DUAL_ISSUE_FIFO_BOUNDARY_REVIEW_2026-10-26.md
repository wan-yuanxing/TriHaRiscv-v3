# 双发射取指队列结构准入检查

本轮只执行五字候选的 compile/synthesize/dev_map，没有执行 PNR、修改默认 CPU 或访问板卡。原生退出0；全部68个输出哈希和冻结输入复核通过。启动记录的阶段识别器错误地要求命令不带参数，原始 FAIL 保留；独立审计匹配带参数的三个成功标记，不重新运行工具。证据见 `../verification/cpu/dualissue_fifo_five_native_gate.json`。

## 实际比较

| 指标 | 最佳六字 v57 | 五字 v63 |
|---|---:|---:|
| CPU-only LUT | 9394 | 9061 |
| CPU-only FF | 4652 | 4536 |
| 实际 FIFO FF（包含复制） | 783 | 667 |
| FIFO CE 组 | 13 | 11 |
| pop0 直接连接的局部 LUT 输入引脚 | 365 | 251 |
| pop1 直接连接的局部 LUT 输入引脚 | 488 | 360 |
| 每个 pop 可达的 FIFO D/CE 引脚 | 1448 | 1217 |
| pop0/pop1 到 D/CE 的局部组合深度上界 | 4/3 | 3/3 |

连接分析限于 FIFO 模块，是保守组合支持关系，不是敏化路径、全核 STA 或时序改善证明。D/CE 分开计数，不代表寄存器数量。网表寄存器总数与原生综合层级报告一致。

旧统计器漏掉同行带 `PAP_PRESERVE` 属性的 FF：v57 曾被计为616，实际783。新测试先失败（1而非2），修复后四个测试通过。历史原始证据不覆盖；此前 FIFO FF 细分数字不能继续引用。CPU-only 总面积来自原生报告，不受该脚本错误影响。

## 共同控制链与预算

v57 最差真实后布线路径：队头PC → 连续性判断 → issue许可 → fetch1_accept → FIFO更新 → 队头数据寄存器。报告为16逻辑级，logic2.637ns、route6.874ns，合计9.511ns；clock skew−0.212ns、uncertainty0.150ns和setup0.136ns使余量为−0.009ns。fetch1_accept该路径扇出483。引用的是历史v57实测，不是本轮估计。

工程设计目标预留0.5ns正余量：按历史非数据开销0.498ns估算，数据路径预算约9.0ns。该预算仅指导结构设计；新布局时钟偏斜会变化，最终仍必须用原10ns全部corner实际STA验收，不能拿预算替代报告。

五字队列减少资源和局部负载，但后部每个表项仍由 remove_a/remove_b、remaining 和宽 shift 共同控制。它没有切断问题边界。本轮不以面积降低作为下一次完整布线的充分依据，保留为容量/性能比较，不启动布线。

## 下一结构：头部寄存器与后部环形存储

本地固定第三方 `rtl/cpu/vendor/src/core/biriscv_decode.v` 已有写指针只在入队时推进、出队推进读指针的组织，可复用其存储职责划分。不能直接替换：原始成对FIFO不提供当前跨取指包双发射和紧凑队列语义。

设计边界如下，尚未实现：

- 保留两个头部载荷寄存器供 issue 读；后部用环形槽，载荷写地址只由注册写指针和入队决定，出队不移动后部载荷。
- 头部先准备0/1/2字消耗后的补充值，晚到 pop 只选择头部结果并更新少量计数/读指针。不能复制整队四套宽候选值，v62已显示其成本。
- B-only消费必须保留A，后部按序补到B；A-only、双消费、无消费也必须保持顺序及全部PC/预测/fault/CSR字段绑定。
- 同周期入出队时，已有后部数据先于新入队数据；后部不足的情况可以用已接受输入补充下一周期头部，但不引入组合输出旁路。空队输入只能在时钟后可见。
- 保持原两字空间预留和总容量，先排除容量变化这个变量。环形读写同槽必须有明确旧值/新值规则，不能依赖RAM未定义冲突行为。
- 当前无效槽的CSR/fault历史会被下游观察。重构必须列出并覆盖其可见行为，尤其flush同时入队、空队以及B-only后残留；不能简单把无效载荷当don't-care。如果保持历史需要整队影子搬移，应重新评审接口契约，而非把原瓶颈藏进影子寄存器。

## 实现前后的门槛

1. 先用独立序列模型覆盖所有合法占用数、四类消费、0/1/2输入、回绕、flush与预测侧带；加入实际载荷破坏负例。对可见无效元数据单独建立断言。
2. 后部载荷D/CE组合支持中不得含pop0/pop1；头部补充不得经新的宽串联选择链。原生综合出现无法解析的原语或连接时，结构检查必须判未知，不能放行。
3. 原生总资源、控制组、头部/写口扇出和完整issue往返路径一起审查。局部深度降低不单独构成准入。
4. 相同固件、-O2、SRAM边界重新测量，必须超过4/MHz；完整退休观察/存储比较、异常和flush定向检查通过。
5. 满足上述结构与行为门槛后才安排一次原约束物理运行。首次失败先审查实际路径；同一结构最多两次有明确归因的物理试验。

本轮结论：完成容量候选的原生结构核查，尚未完成头部/后部方案实现，也没有100MHz通过结果。
