# CPU 512/512/4 与 O2 对照实施

2026-10-20。用户指定BTB/BHT/RAS=512/512/4，CoreMark固定-O2。保留六级单发射、现有PC索引两位预测算法、GShare关闭、32KiB SRAM、100MHz及原IO/hold/多corner约束。容量相同不代表与历史tournament算法相同。

当前BTB是全相联并行比较结构；扩大到512可能显著增加资源及查询扇出，因此必须重新量资源和后布线时序，不能复用32项版物理通过结论。原32/512/8、O3下载包和cpu-coremark-serial-ready-20261020标签保留。

实际CAM512实验通过5次CoreMark，1690312周期、短测2.958033/MHz；PDS编译停留于DFF推断，私有内存实测52.72GB、工作集21.23GB，已终止本轮owned PDS并保留退出记录和完整快照。历史512项BTB本来采用索引表，因此调整为512项直接映射、两bank、Pango原生异步读RAM。沿用当前寄存器堆的原生RAM/有效位模式，索引和tag核对方法参考已有直接映射BTB；不加入同步查询等待拍，BHT/RAS共用原逻辑，CAM保留在显式旧后端中。独立oracle覆盖全部512地址、tag冲突、元数据、目标保持、上下word选择、并发训练及复位/失效，故障注入必须拒绝。

用户追加串口CoreMark/LUTs。分母取本轮板级综合报告u_core层级的总LUT数（其中包括作分布式RAM使用的LUT，不重复相加），排除SoC外设；先测量面积，再用测量记录生成固件常量。最终物理构建再核对实际CPU LUT数与常量一致，所有计算和串口输出在计时区间之后。原始算法、100MHz和IO/hold约束保持。
