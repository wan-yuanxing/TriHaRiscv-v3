# 原生寄存器堆提前读取

备份为96b8495及cpu-board-pre-parallel-read-20261020。该版保留原CPU和此前全部诊断，片上系统100MHz通过标签独立保留；尚无板级通过包。

实际路径为issue PC[2]→两槽指令选择→源寄存器地址→异步RF读取/旁路→ALU。仅改变PC算术或复制选择位都未改善实际全局时序。增加流水拍会改变性能，因此选择在现有周期内提前读取，保持六级单发射和顺序发射规则。

仅在原生单发射配置复用两个既有triha_regfile实例，分别以取指槽0/1的原始rs1/rs2作固定地址。两个实例接相同的现有写回、时钟和复位。每槽分别应用原有WB0、WB1、E2-0、E2-1、E1-0、E1-1的旁路优先级和最终x0覆盖，再用原PC位的过程if选择实际操作数。RF写行为、发射资格、取消、异常、IRQ、预测器和总线周期不变；双发射及其他RF后端保留原实现。

新增的两个读口用于预读，仍只允许每周期一条指令发射。复用现有GTP_RAM32X2DP封装和既有同步写/异步读语义，没有新工具或厂商源码变更。预计原生RAM单元32→64，额外LUT、FF及实际布线由PDS测量，不用估计宣称时序收益。

验证先观察旧版真实失败：RAM地址仍随PC变化。实现后4000组RF/旁路/槽选择测试累计16512项，覆盖非零内容、重写、复位、重叠旁路最高优先级、x0、未知地址/标签和未知选择位，全部通过；真实输出位翻转被拒绝。还需以三seed单/双整核退休/store/异常、IRQ/mret、CoreMark精确周期/CRC、板级两次启动和真实初始化字节损坏核验，并以新PDS实际后布线六项约束判断。不是完整ISA/formal证明，不提前准入部署。

验证终态：13项运行哈希绑定，CoreMark仍1685831cycles/1467843WB；CPU-only6017LUT/5172FF/64分布式RAM/0DRM/4APM，较板级原版+30LUT/+32RAM，FF不变。首轮-0.455ns，SRAM→load旁路→分支→PC CE为最差；收拢SRAM后最差转为BPU -0.845ns，均未通过。当前不能交付。
