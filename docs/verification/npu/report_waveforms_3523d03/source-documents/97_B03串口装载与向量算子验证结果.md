# B03 串口装载与向量算子验证结果

2026-10-28，基于93/94/95规格。当前选中实现为 `b03_uart_control_bram`、`b03_vector_exec_compact` 和冻结 PC 工具；本文记录独立验证，整网、真实HMIC、最终PDS和实物验收另按各自报告判断。

## 控制与PC通路

计算域100MHz、UART115200/8N1，RX=B24、TX=C24；引脚来自配套pg2l100h远程升级例程FDC第102/80行，RX双FF同步。UART只接唯一内存块服务。HELLO/STATUS可在DDR校准前返回；READ/WRITE为窗口相对地址，检查后统一加基址，地址0合法，任意字节≤256，按32B和4KiB边界拆分。

帧使用A5 5A、版本/命令/序号/长度、payload和CRC32。相同序号和内容重试不重复WRITE/START/ACK，同序号不同内容拒绝。运行及结果待消费期间保护写入；SET_TASK锁存BMD3，START交父执行器，GET_RESULT只读最终元数据。普通内存请求保持到退休或真实会话失效。

最终UART使用一个实际1024×18 E1 RAM的低8bit存储RX/CMD双缓冲、128B任务及256B READ回复，共0.5 DRM36等效；元数据仅保留固定小寄存器。RX和TX、任务复制及本地W/R使用RAM同步读取和单byte skid。低速串口允许这种访问延迟，避免32个动态byte读写口展开为FF交叉网络。

PC入口为 `jiaoben/python/run_b03_pc.ps1`、`yunet/python/b03_pc_tool.py`。PC装载输入、程序、权重和POST表，不执行卷积、解码或NMS。完整运行核查128B NPR3头、头CRC、任务身份、几何、地址版本、记录数/偏移/CRC及scope0/release0。DDR读取后再次HELLO/GET_RESULT，检查会话和元组仍相同且live；ACK后再观察HELLO。复位、live变化或ACK错误会保留原元数据、raw字节和错误报告，不生成成功框图。这是有限的scope0观察，不证明一般跨master原子发布。

同一冻结bundle只更换输入可复用epoch；更换程序、参数或Sigmoid表先reset，再HELLO确认新epoch后重装。PC默认上传不自动reset，不能假设同址参数热替换会透明清缓存。

UART覆盖地址0、跨页256B访问和保护字节、非法范围/CRC零副作用、513B超长/截断包、完整512B未知命令和非法WRITE、重复seq/冲突、START/ACK幂等、busy写保护、结果保持、取消、会话复位和超时恢复。实际8个本地请求全部退休，3次START、3次ACK和3次重放。fake执行器仅验证协议合同。

PC测试包含噪声/碎片/坏CRC/错误序号重同步、CRC或丢ACK后的精确重试、777B分片读回、seq回绕、BMD3大小端、NPR3损坏拒绝。完整固定框fixture验证中文PNG、320×320 U8/BGR/NCHW307200B准备、装载、START、头核查、显示和ACK；该固定框图片不作为模型识别人脸成果。4种错误分别为读取期间reset、二次GET_RESULT变live0、ACK设备拒绝和ACK期间reset，均保留原tuple/raw且不产生成功图片。实际Windows PowerShell执行 `--port COM7 run --help` 成功，未打开COM口。

向量保留Add、Transpose、Reshape、Sigmoid通用算子，借用唯一共享量化器，不新增量化APM。14组覆盖102400B/257B Add、Cin1/Cin4及U8/S8/I16/U16转置、超过128B分块的152B U16转置、12800B Reshape和额外dtype奇数尾、4200点S8→U16 Sigmoid，以及7/2系数RNE/奇偶LUT索引、clamp、epoch/地址变化重载和同epoch表复用。

向量A/B/O缓冲使用8个16bit×1024 E1 bank的低8bit，低3位bank交织，共4 DRM36；8193项LUT另用两组2048×32实际E1和最后16bit FF，共4 DRM36，合计8 DRM36。R256先接skid再每CE写8个固定bank；Q8同row读取；W每次组8B后保持普通握手。14组共14824请求、8948读beat、5876写beat、2662个CE0数据beat、2360个掩码边界；保护区、背压和CE合同由TB直接检查。
