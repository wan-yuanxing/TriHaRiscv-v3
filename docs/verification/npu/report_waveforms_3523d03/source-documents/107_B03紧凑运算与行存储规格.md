阵列保留默认ACC_BITS=32和完整zero/load/pipe-clear语义，load用256个固定目标的单一enable译码，避免4个动态写口；非法weight仅16次检测和最低有效M/Co编码；return_bad及overflow按16行分层优先编码，保持先产品身份错误、再溢出的优先级。完整模型可选ACC_BITS=23：每次init后最多128个合法K，a∈[-128,255]、w∈[-127,127]，原始MAC绝对值≤128×255×127=4145280<2²²；bias在量化器另以I32加，因此sign-extend23与I32参考一致。23模式拒绝任意P reload；32模式继续承载旧诊断spill/reload。图准入K≤128不放宽。

layer的Dense取数显式限定m=q_issued[4:1]、half=q_issued[0]，每lane固定Co余数，避免8个32bit integer索引各读取256个acc。参数按8channel group选择，8lane余数固定，避免qc+lane的64路宽选择。O写入的Co group必须为8对齐；每bank固定A/B目标，按plane word轮转lane，A/B组地址共享，仅13bit tile字节偏移/11bit O word参与计算。

量化保留原32个实际APM和一次RNE语义。compact输出只承诺dtype夹紧后的16bit值、mask/tag/error，不冒充旧模块完整I64 debug输出。guard/sticky按小组前缀OR和8bit选择产生，缩窄舍入/夹紧域必须通过旧独立数学golden与正负极值/shift1..62/半值偶舍入验证。旧完整I64产品/舍入模块及证据保留。

验证要求：默认32阵列回归旧控制/随机/溢出及P reload；23阵列覆盖128×U8×正负127极值和非法load拒绝。紧凑layer以真实E1/APM和实际blockDMA跑空间golden，再接完整79op/九头和最终框。只有新PDS实际资源、STA及位流齐备才宣称可下载；未测板上30fps保持开放。


## 实测实现与边界（2026-10-28）

旧fast全工程ADS遇到未映射bmsSMOD而退出1，220806 LUT只是已映射部分的下界，不能称综合成功。compact运算源全部另名保留；对非负bank索引使用窄位截取/与3，避免有符号integer取模。

### 阵列采用APM真实post-adder

`b03_array_apmacc16.v`与`b03_mac_pair_compact.v`使用官方GTP_APM_E2的USE_SIMD=1、USE_POSTADD=1、P_REG=1、MODEY=001（mi）、MODEZ=0001（pri）。低、高24bit累加器不传递半间进位。X/Y在E0、M在E1，E2的CEP由完整阵列global commit控制；产品身份、front错误或控制冲突发生时，128个CEP全部关闭，保持原子性。RSTP由reset/clear/init/合法zero控制；pipe_clear只清乘法与token管线，保留累加器。

该实现拒绝P load，in_k含bit7即拒绝，因此每次init最多128项。U8/S8输入与合法S8权重的raw MAC绝对值≤4145280，真实24bit P不会溢出，sign-extend到I32完全等于冻结golden。任意I32 spill/reload与溢出诊断继续由默认32bit的`b03_full_array16_compact.v`和原模块承担，不能把APM版本解释为任意P载入模式。

隔离PDS实际exit0、无未映射RTL、VM原始primitive与SNR相等：`build/platform/b03_array_apmacc_area_dev01/result.json`为2826 LUT、794 FF、128 APM。第一版23bit fabric累加器16351 LUT已保留，最终选择实际post-adder方案。
