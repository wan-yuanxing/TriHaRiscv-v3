# 双发射 Cache 开关性能矩阵

2026-10-23，独立分支 `cpu/dualissue-windows`，实现基线 `e649aef`。
GCC15.2、`-O2`、无 LTO，CoreMark 五次短 RTL 迭代；四组均通过 CRC。

| 发射模式 | DDR Cache | 周期 | 短测 CoreMark/MHz | WB 观测 IPC |
|---|---|---:|---:|---:|
| 单发射 | 关闭 | 10,613,264 | 0.471109 | 0.136475 |
| 单发射 | 开启 | 2,014,969 | 2.481428 | 0.718844 |
| 双发射 | 关闭 | 10,892,242 | 0.459042 | 0.132980 |
| 双发射 | 开启 | 1,781,952 | 2.805912 | 0.812843 |

四组使用相同加载镜像、相同 AXI128 数字内存模型。Cache 关闭为同一 DDR
边界的真正旁路，不能用 TCM 跑分替代。每种发射模式的开关对照均重新核验
全部冻结输入/输出和完整 WB/store 流：除首个绝对 cycle 值及其保存 store 外
相同。每组计时 WB 1,448,448 条、store 70,839 次。JSON 保留完整对照摘要
和原始运行定位：[证据](dualissue_cache_matrix.json)。

Cache 关闭时，双发射在该共享总线模型下反而慢约2.56%：I 读请求从925,692
增加到967,047；D 读279,511和完成下层写73,296不变。该计数表明额外取指
流量存在，尚不能单凭它断言全部周期差的因果分解。Cache 开启时，I/D下层
读分别391/134，两模式相同，双发射吞吐提升13.076503%。

片上 TCM 作为独立边界：单/双分别1,646,469 / 1,411,226周期，短测
CoreMark/MHz 3.036802 / 3.543019。同一ELF比较已通过，见
[前一批基线](dualissue_cached_baseline.md)。

用户明确选择片上 SRAM/TCM 的最高性能超过4 CoreMark/MHz为主目标。
以五次迭代计，需要不超过1,249,999周期，当前仍需减少161,227周期。
目标尚未达成；下一步按实际停顿和配对观测筛选优化。保持六级、-O2和原有
指令/异常语义，不通过更换内存模型或混用边界宣称达标。

以上均为短 RTL 仿真；原始短时长警告保留，不是官方分数或板级测量。
双发射 CPU-only 资源和实际100MHz后布线时序仍待验收，未访问板卡或串口。
