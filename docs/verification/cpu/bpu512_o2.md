# 512/512/4、O2 与 CoreMark/LUTs

本轮按用户要求将正式CPU包装配置改为BTB512/BHT512/RAS4，CoreMark三个构建入口固定GCC-O2，无LTO。BHT仍是PC索引两位饱和计数器，GShare关闭，未实现历史tournament方向预测算法。六级单发射、原100MHz及IO/hold约束不变。

512项BTB采用直接映射、两bank、Pango原生GTP_RAM32X2DP，无新增查询等待拍。索引使用PC[10:2]，高位tag参与核对；同时查询一个64位取指字的两个分支槽，优先当前精确word，其次上word。复用原BHT/RAS逻辑及已维护的原生RAM/有效位模式。已知目标在not-taken命中训练时保留，tag冲突替换；复位/失效清valid，RAM不整体复位。

原全相联512项对照完成CoreMark5次，1690312周期、CRC正确。其PDS停于DFF推断，私有内存达到52.72GB、工作集21.23GB后由本任务终止owned进程；终态为退出失败，未得到CPU LUT数或时序结果。快照及说明保存于build/soc/bpu512-area-20261020T053204168832Z，不称为FPGA面积超限或时序失败。
