# 附录 B.4.6 建议替换片段

原强制输入零比较配对测试的失败已定位为测试夹具与当前接口不一致。夹具未同步提供队列中的简单 ALU 资格、寄存器角色、操作数零标志和预测下一 PC，且仍沿用禁止未提前判定分支配对 ALU 的旧期望。原测试与 FAIL 记录保持不变；完整驱动现行接口的后继夹具通过 6168 个检查点。本次未修改 RTL。

采用真实取指、预译码、FIFO、发射与 LSU 路径执行的 72 次定向程序全部通过。其中 60 项覆盖 BEQ/BNE、两种 x0 源位置和 ALU/Load/Store 后继，在不跳转、实际跳转、A/B 加载 RAW 及分支目标不对齐异常下检查配对与恢复；另有普通双源分支 6 种组合各重复两次作为对照。确认不跳转时，后继 ALU、Load、Store 正常执行；未确认或跳转时，LSU 后继不会提前发出，推测 ALU 在恢复或异常时被取消。程序同时检查写回值、外部访存次数和每次 A→B RAW 序列。错误开放 LSU 配对及关闭 B 取消的故障注入均触发相应断言。

额外前递检查中，一份仍按 PC[2] 选择 A 槽的旧测试保留为 FAIL；按当前 FIFO 队首契约并同步 E2 零标志的后继测试通过 694800 个检查点。源码身份、逐项覆盖和全部通过/失败记录集中登记于 `docs/verification/cpu/document_review_zero_pair_20261102/`。以上结果属于定向仿真，不扩展为完整 ISA、物理时序或板级验收。
