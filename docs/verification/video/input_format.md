# 检测输入BGR、补行与C8格式验证

基线09fd86d；设计/计划f21f011。用户确认NPU模型清单仍未提供，本批实现固定布局及量化前后接口，不定义模型尺度。

## 两个明确的数据类型边界

`detect_input_pad`接收160×120 RGB888，将高/中/低字节R/G/B交换为B/G/R，并在底部生成8行raw零像素，输出160×128 BGR及row_last/frame_last/padding。补行是量化前原始零，不能直接当成量化张量。单输出槽保持至ready，消费可与新像素接纳或补行生成同拍。

`detect_c8_pack`先接纳显式`req_zero`，再接收外部已经量化的BGR字节与三个元数据。它校验行/帧位置、padding标志及补行通道的量化零值；不执行缩放、舍入、饱和或模型量化。请求之后的req_zero变化不影响本帧。每像素内存顺序为B,G,R,zero×5，两像素依次位于128bit低/高64bit。奇数宽行尾不跨行拼接，keep=00ff且无效高64bit清0；偶数宽完整拍keep=ffff。

默认C8布局160×128×8=163840字节，行有效1280字节。最后输出拍消费后才置本地done，错误撤销done；该状态不代表DMA B响应或正式INPUT_READY。未知请求/被接纳payload/元数据错误置sticky fault，输入停止，但已公开输出保持至ready；协调clear/reset可取消半拍、补行或末拍。
