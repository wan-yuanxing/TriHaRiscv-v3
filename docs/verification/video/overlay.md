# F3b 框、五点与单头像像素组件验证

基线`a6dfeda`，依据[全屏设计](../../superpowers/specs/2026-10-19-fullscreen-display-design.md)，
执行[本批计划](../../superpowers/plans/2026-10-19-display-overlay.md)。本批完成独立像素
组件，板卡继续运行F2静态全屏桌面镜像。未生成三模式板级位流，未下载或写Flash。

## 行为与边界

`display_overlay`在800×600原图坐标绘制最多16个框和每框5点；BOX可独立关闭点，
AVATAR只覆盖一张256×256 RGBA头像。结果必须有效、同frame且有脸，否则原图透传。
框为signed16半开端点，先裁剪再绘制内边框；无面积框连同其点忽略。主人脸框优先
于普通框，点优先于两类框；点半径默认2、线宽默认2。颜色及合法参数边界见
[接口](../../interfaces/video.md)。

`avatar_sample_map`以9级几何/二进制小数流水精确计算最近邻地址，保留未裁剪目标
矩形的源原点，允许65535跨度和跨四边目标。没有逐像素变量除法组合链。18bit地址
为RGBA字节偏移，4字节对齐，最大262140；非预乘Alpha使用规格精确四舍五入公式。

输入边沿n对应n+8输出请求，外部同步素材缓存n+9采样请求并注册响应，n+10消费
响应，RGB/坐标/frame_id/DE/HS/VS/SOF及叠加标志在n+12输出。13级流水不反压；
固定响应槽缺数/错误只影响对应像素并锁存故障，后续健康供数继续显示。供数器不得
滑动或重排响应。无效槽RGB可未知，内部已隔离；有效且成功的RGBA须已定义。

当前测试用同步过程纹理供数，不是素材DDR行缓存。调用方必须提供同钟已提交记录；
组件不处理像素CDC/原子帧边界、raw槽释放、MODE管脚或正式显示MMIO。接入后仍须
把首像素/提交事件和全部引用退休对齐到新流水末端，不能因本组件仿真通过而提前归还槽。

## 运行与结果

```powershell
python scripts/video/run.py --suite overlay
python scripts/video/run.py --suite raw_display
python scripts/video/run.py --suite mode_control
python -m unittest discover -s tb/video -p test_*.py
python scripts/video/build_pds.py --target video_overlay --stage synth
```

本批最终运行overlay 12场景、raw_display 46场景、mode_control 24场景，共82份
仿真PASS日志；Python85项通过、1项Windows符号链接权限跳过。最终叠加核验858756
个退休像素及621263个有效采样请求，包括全部480000个全屏有效像素、全部65536
个纹理地址和256种Alpha。故障/复位场景中，请求可能先发出后被协调复位清空，
请求数与退休头像/故障像素数因此不要求相等。

覆盖16框及末lane、第五点/开关/覆盖优先级、负/极端点坐标、四边裁剪、半开末端、
零面积/反向目标、1像素/放大/缩小/全屏/最大跨度、80组随机signed目标、错帧/无脸、
逐拍模式变化、空白/越界光栅、缺数/error、非请求响应、未知素材、恢复及所有流水
阶段中的复位。输出空泡断言防止复位后的旧DE/叠加标志逃逸。

SV只驱动像素、同步供数并转储；Python独立按矩形集合/直接整数除法计算地址和
混合，检查输出顺序、身份、同步、标志与sticky故障。延迟原图/无请求RED替身在
当前测试中分别因框像素错误和缺头像采样请求失败。独立审查另核对了5319个像素、
3679个请求及全部65153种合法混合中间值的除255恒等式，8/8定向RTL突变被检测。

审查复现了无效素材槽RGBA=X时，单独令alpha=0仍因`X*0`污染原图的错误。当前
版本同时隔离无效foreground，正式TB对无请求/缺数/error槽注入未知RGBA，父复现
RED、修复GREEN及独立重验均通过；未解决实质问题为0。来源及100项审查产物哈希
已核对；93项既有dirty/冻结来源保持原样。

F3a完整37套件/198输入基线中，196项输入保持字节一致，仅run.py/build_pds.py增加
显式新组件入口。本批重跑上述三个受影响套件，未重跑完整all；不把旧337份完整
回归日志标为本批运行。全基线日志哈希与既有交付记录一致。

## 综合估计与后续

最终组件综合为10637 LUT、1645寄存器、0 DRM、6 APM。25ns像素时钟及同钟注册
调用方/素材响应边界的0ns输入输出delay已施加，输入组合逻辑包含在估计中；slow
setup WNS为+15.961ns、3592端点且无setup失败。slow hold估计为-2.470ns、1770
失败端点；没有布局布线，不能宣称时序闭合或上板通过。实际板级布线须重新闭合
setup/hold、审计CDC和外部接口时序。组件目标已验证拒绝bitstream阶段。

首轮仅clk约束的估计及一次`mode`向量通配缺失导致的约束拒绝不作为最终签核；
最终结果来自修复foreground后的独立构建与固定字节快照。
