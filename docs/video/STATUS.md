## 本轮硬件连接观察

2026-10-16 只读查询 `Win32_SerialPort` 时，仅枚举到 COM1，没有枚举到板卡 CP210x 串口。本轮没有扫描 JTAG 或下载器，因此不能据此判定板卡/JTAG未连接。到 V013/V015 板测时核对实际数据线、供电、下载器与串口；纯 RTL/IP 开发可继续。

本批回归：11 项 Python 测试中 10 项通过，1 项因 Windows 不允许创建测试符号链接而跳过；硬链接保护和 Windows 文件名别名测试已通过。完整光栅测试验证三帧、复位恢复及综合顶层接线。结果与输入哈希见 `docs/verification/video/evidence/windows_kickoff.json`。

提交管理：本批仅以 Video 文件建立本地提交，技术报告已有修改保留；未推送或合并到 main。版本以 `git log` 的 `feat(video): establish native Windows bring-up baseline` 提交为准，验证摘要与源码哈希绑定。
