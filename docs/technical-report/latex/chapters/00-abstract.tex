\sffamily\bfseries\zihao{-2} 摘\ \ 要
\end{center}

针对嵌入式智能视觉应用中通用控制、密集计算与连续视频处理的不同需求，设计了基于紫光同创PG2L100H国产FPGA的TriHaRiscv异构视觉处理系统。自主设计的RISC-V CPU采用适配FPGA同步存储与时序约束的六级顺序流水线，支持综合时配置单、双发射。前端结合指令队列与跨取指包配对供给指令，利用动态分支预测减少控制流等待，通过操作数前递、记分牌和互锁处理数据相关与资源冲突；配置独立指令与数据缓存，并共享乘法和访存单元，权衡处理性能、资源开销与实现复杂度。

针对YuNet人脸检测网络构建定点NPU，采用广播式并行乘加阵列和独立深度卷积通路，利用片上特征与权重复用、DMA搬运及硬件计算图执行完成模型运算。CPU负责整帧任务调度、检测框解码和非极大值抑制，NPU执行卷积与辅助算子，视频子系统承担图像预处理、帧缓存读写和显示合成，各模块经共享DDR协同工作。

系统接收800$\times$600 HDMI视频，实现全画面人脸检测及RAW、BOX、AVATAR三种显示模式。三帧槽通过提交与释放握手维持图像和结果对应，使采集、推理与显示重叠运行；透明头像依据主脸位置与尺寸跟随缩放，采用无损行区间纹理缓存和流式像素合成，减少片上存储需求并避免整帧合成图写回。

在100\,MHz独立CPU板测中，片上存储配置的单、双发射CoreMark/MHz分别为3.055和4.093。完整应用采用50\,MHz计算时钟，整机综合占用45,716个LUT，内部后布线最差建立、保持裕量分别为+0.100\,ns和+0.131\,ns。完整模型的数字联合仿真通过三模式逐像素核对，仿真结果生成率约2.77次/秒；实板完成人脸检测、头像跟随、透明合成及无脸清除与恢复的功能验收。
