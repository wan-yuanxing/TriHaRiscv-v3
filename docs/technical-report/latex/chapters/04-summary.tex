\chapter{总\ \ 结}

\section{可扩展之处}

系统保留同帧原图、人脸框、五点及头像编号接口，可在检测后增加裁脸、缩放和表情分类。
扩展时在帧记录中增加消费者阶段，延长原图生命周期，并把表情结果映射为头像编号。
新增模型的推理、数据搬运和后处理开销需要计入整机帧率与延迟分析。

CPU可进一步研究前端供数、预测策略和流水线并行度，NPU可扩展算子及并行规模。
扩展工作沿用公共地址、寄存器和版本管理方式，分别检查指令语义、整数结果、共享存储顺序及FPGA时序资源。

\section{工程取舍与心得体会}

六级单发射结构将取指请求与返回分开，在保持顺序提交的同时组织Cache和总线等待。
CPU承担控制与有限候选处理，NPU承担卷积及张量运算，Video承担逐像素处理，使软件调度粒度与硬件数据粒度对应。
深度卷积采用通道独立的供数和累加方式，避免将稀疏连接转换成低利用率的密集计算。

共享DDR通过不可缓存区、完成响应和帧所有权管理保证数据交接。
三种全屏模式共用原分辨率底图和同帧结果，逐像素合成直接输出，省去整帧叠加图的写回；三帧槽允许采集、计算和显示重叠，旧引用退休并完成释放确认后再复用缓存。
性能分析从CPU退休事件、NPU逐层周期延伸到实际显示事件，使计算开销、排队和扫描相位能够分别定位。

模型导出、整数参考和视频前端采用相同的预处理与舍入规则，减少跨模块数值差异。
统一配置和版本标识将硬件、固件、模型及素材组织为可复现的运行组合，便于比较配置变化及定位接口问题。
