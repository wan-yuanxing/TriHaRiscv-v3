# CPU冲刷后的副作用隔离验证

**目标：** 在既有CPU工作树验证真实分支重定向和加载访问异常后，错误路径不产生存储、MMIO、CSR或寄存器写入。

**范围：** Windows GCC和ModelSim；默认六级单发射及512/512/4预测配置；通过公开指令与数据端口激励。新建测试台和固件，生产RTL不变。

- [x] `sw/tests/squash_runtime.S`：三种分支错误路径，以及四种长延迟加载异常后的年轻指令；各正确路径有确定结果和完成计数。
- [x] `tb/cpu/tb_cpu_squash.v`：独立内存/MMIO状态，观察CSR提交和实际退休；要求错误指令确实被取回，并核对错误路径零退休、零可见副作用。
- [x] `scripts/cpu/run_squash.py`：显式冻结源码/工具；保存固件、日志、WLF/VCD；正例返回0，四种实际错误输入负例返回1。

- [x] 按真实轨迹说明阻塞式访存边界，不虚构跨重定向的已接纳加载响应；不注入无请求或重复响应。
