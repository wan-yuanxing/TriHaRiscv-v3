# F2 raw 全屏板级实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** 单次 HDMI 同帧三分支采集后，以 raw RGB888 800×600 完整扫描，验证实体 KEY0 重采。

**Architecture:** 新增独立 video_raw_board_top/video_raw_engine，复用已冻结的三分支引擎流程、HDMI 初始化/复位、DDR IP及桥；显示实例替换为 raw_display，提交 raw_base/RAW_STRIDE。旧双窗目标与源码保持不变。UART 6/8 保持采集/输入诊断，9 明确表示每扫描600行的 raw 全屏。

**Tech Stack:** Windows PowerShell/Python、SystemVerilog、Icarus、PDS PG2L100H。

## 文件职责

- 新增 rtl/video/video_raw_engine.sv：三路读回后提交 raw；非法记录转为板级错误0x69，保持组件拒绝接口语义。
- 新增 fpga/pg2l100h/rtl/video_raw_board_top.sv：继承已验证硬件连接和协调复位，UART display type9。
- 新增 fpga/pg2l100h/project/video_raw_board.json、constraints/video_raw_board.fdc：显式来源与实际存活CDC端点，保留8ns core与6ns束约束。
- 新增 tb/video/tb_video_raw_engine.sv、tb_video_raw_board.sv、test_raw_board_packets.py：独立raw逐像素、三分支oracle、故障及复位、type9解码和资格。
- 扩展 scripts/video/run.py、build_pds.py、package_board.py、program_board.py、read_board.py：正式入口及明确验收字段。
- 更新 docs/video/README.md、STATUS.md；新增 docs/verification/video/raw_board.md 和 evidence/raw_board.json。
