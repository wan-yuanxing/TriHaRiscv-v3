# Video overlay 共享像素边界运算

在已授权的 Video 资源/125 MHz 收敛范围内优化 BOX 几何组合逻辑。完整
static-AW probe 的综合基线为 32,881 LUT，其中 overlay 为 11,401 LUT。
本轮不改变 ABI、帧所有权、模式、16 框/每框 5 点、颜色优先级或流水拍数。

选择共享像素侧阈值：点命中从 `pixel >= point-R && pixel <= point+R`
改写为 `point >= pixel-R && point <= pixel+R`。框内部边缘从
`pixel-left<W || right-1-pixel<W` 改写为
`left>pixel-W || right<=pixel+W`；Y 轴相同。像素阈值在所有 lane 间共享。
仅缩短原整数位宽仍保留重复加减；串行复用各点则涉及吞吐/流水变化，本轮
均不采用。裁切和退化框抑制点的顺序保持。

像素输入为无符号 11 位，范围 0..2047；合法 W=1..800、R=0..31。
共享阈值的全集为 -800..2847，带符号 13 位足够。坐标仍为带符号 16 位，
不截掉其符号位；比较由带符号操作数作符号扩展。常量显式定宽，避免
无意恢复 32 位运算或将负值解释成无符号。RGB/alpha 与 avatar 路径不改。

先冻结 HEAD 的 overlay 为参考，所有输出逐拍作四态比较，包括 reset 和
avatar 请求；独立 Python oracle 继续检查数值与 13 级时序。补充坐标极值、
阈值两侧、所有 lane、宽线/零半径/最大半径及未知坐标测试。编译可运行的
边缘/符号/优先级错误变体必须被拒绝，性能 RED 使用真实综合基线。

使用同一个 video_overlay 目标进行改前/改后综合，并重新综合完整 probe。
只有实际 LUT 下降才接受性能收益；综合和布局均不能代替最终布线时序。
旧 seed11 route 使用冻结数据库，独立保留其结果，不修改其绑定解析器。
