# 连续 RAW 上板交付

用户已批准先交付连续 RAW，再推进连续 BOX/AVATAR；暂停不阻塞板级目标的 LUT/探针优化。

- 新增 `video_live_board`，保留已验收的静态目标。复用其 HDMI 初始化、128 帧启动保护、125 MHz DDR、40 MHz 输出和管脚。
- A/B 两槽轮换。每次保留 raw、preview、320×320 BGR NCHW 三分支。只在好 EOF、全部写响应及捕获端排空后发布 RAW。
- 新帧在输出帧边界提交；旧槽直到显示器 release 后才能重用。无空槽时等待，允许跳过输入帧，禁止覆盖正在显示的槽。
- 板级诊断控制器独占 Video DDR 端口；不代替最终 CPU 帧池及 SoC 可见性契约，不宣称 NPU 已工作。
- 去掉每帧全量诊断回读；记录捕获数、提交数、释放数、扫描数、源 CRC、欠载和首错。故障保持、停止发布并排空已承诺事务，KEY0 协调复位。
- 输入/输出仍为 800×600、60.32 Hz。更新率由实测交付，不先宣称每秒 60 个新帧。

验收：多次变化输入自动更新，完整帧且无撕裂；仿真覆盖双槽复用、DDR 等待、复位和错误；实际板级布局布线时序通过后下载并持续记录，现场确认动态画面。
