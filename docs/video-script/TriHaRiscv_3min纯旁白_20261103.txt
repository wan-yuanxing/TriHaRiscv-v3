TriHaRiscv 三分钟项目介绍｜纯旁白
资料截止：2026-11-03
录制时仅朗读各段正文，时间标签不读。

[00:00–00:15]
大家好，我们的作品是 TriHaRiscv，基于 RISC-V CPU 与 NPU 的异构视觉处理系统。我们在紫光同创 FPGA 上，将处理器设计、性能测评和人脸检测应用连接起来。

[00:15–00:40]
CPU 采用 Verilog 构建，支持 RV32I 基础指令及乘除法扩展，使用六级顺序流水线。我们通过数据前递、相关性检查和分支恢复处理流水线冲突，并提供综合时可选的单发射和双发射配置。双发射通过两条执行通路，提高相邻指令的并行处理能力。

[00:40–01:00]
存储方面，指令和数据缓存各为十六 KB，均采用两路组相联，数据缓存支持写回和写分配。动态分支预测减少控制流等待，机器模式异常与中断支持程序恢复；串口和板级控制接口用于装载、调试与状态输出。

[01:00–01:30]
在一百兆赫兹下，我们完成了 CoreMark 一点零的五千次迭代板测，各组运行时间都超过十秒。双发射配合片上 SRAM，达到每兆赫兹四点零九分；使用一级缓存和 DDR 时，达到三点一五分。我们同时统计 CPU 核资源与单位逻辑资源的性能，比较不同配置的效率。

[01:30–01:50]
我们采用指令集回归、模块仿真和实板测试分层验证，并检查异常、中断和缓存访问。针对 CoreMark 的链表、矩阵与状态机算法，我们使用片上逻辑分析工具观察指令完成和流水线状态，让性能分析有波形与数据支撑。

[01:50–02:15]
在应用侧，我们部署了 YuNet 人脸检测模型。CPU 提交整帧任务，NPU 自动执行计算图，以八位定点运算加速普通卷积和深度卷积。CPU 随后完成检测框解码和非极大值抑制。三帧槽管理原图与结果，显示端在对应原图上直接叠加检测框。

[02:15–02:45]
现在展示已上板运行的人脸检测。我们从 HDMI 输入八百乘六百的视频，由开发板完成预处理、推理和画框。人脸移动时，检测框随位置更新；切换到无人脸画面后，检测框消失，后续画面继续更新。当前应用的 CPU 与 NPU 运行在五十兆赫兹。

[02:45–03:00]
目前，我们已完成 CPU 基准板测和人脸检测功能验证，并归档源码、位流与复现材料。下一步将实测端到端延迟和持续帧率，继续优化计算与数据搬运。谢谢。
