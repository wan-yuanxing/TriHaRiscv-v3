TriHaRiscv 三分钟项目介绍｜优化版纯旁白

[00:00–00:15]
大家好，这是 TriHaRiscv。我们在紫光同创 FPGA 上构建 RISC-V 处理器，用性能测试和人脸检测，展示处理器设计与系统协同。

[00:15–00:40]
CPU 采用六级顺序流水线，可在综合时选择单发射或双发射。单发射每周期最多发射一条指令，双发射在满足配对条件时最多发射两条。我们围绕两种配置设计指令供给和数据前递通路，再通过实测比较性能与资源开销。

[00:40–00:55]
缓存复用指令和数据，分支预测提前选择取指方向。配合异常、中断处理和串口调试，我们检查不同存储条件下的程序运行情况。

[00:55–01:25]
在一百兆赫兹下，四组配置均完成五千次迭代，运行超过十秒。双发射配合片上存储，达到每兆赫兹四点零九三分。双发射配置得分更高，单发射配置的单位逻辑资源性能更好。这里比较的是完整配置，差异不能全部归因于发射宽度。

[01:25–01:40]
验证分为三层：指令集和模块仿真检查功能，实板测试核对运行结果，片上逻辑分析观察流水线状态。测试结果与原始波形一并保存。

[01:40–02:05]
进入应用，我们采用关闭缓存的精简单发射 CPU 承担调度，CPU 与 NPU 运行在五十兆赫兹。YuNet 的主要卷积由 NPU 以八位定点运算完成，硬件支持普通卷积和深度卷积。CPU 再完成检测框解码和非极大值抑制。

[02:05–02:45]
现在看实板演示：视频源连接开发板，处理后的画面送到显示器。输入为八百乘六百。人脸入画后出现检测框；位置改变，框随之更新。系统将检测结果与对应的原始画面匹配，再叠加检测框。切换到无人脸画面，框消失，后续画面仍继续更新。

[02:45–03:00]
我们已完成可配置 CPU 的性能板测和人脸检测整机功能验证，并归档源码、位流与复现材料。后续将补充应用测速，优化计算与搬运。谢谢。
