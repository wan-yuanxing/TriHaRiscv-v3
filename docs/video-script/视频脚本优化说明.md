## 三、重点改动与原因

1. **CPU叙事集中到可配置设计。** 顺序为六级流水线、综合时单/双发射、指令供给与前递、性能和资源比较。RV32IM、Zicsr、Zifencei及Verilog放在架构画面，避免连续报术语。
2. **CoreMark增加配置分析。** 保留四行完整数据；口播只突出4.093及“双发射得分更高、单发射单位逻辑资源性能更好”。同存储条件下的约34.0%和26.2%用图表高亮，并口播完整配置比较的限制。
3. **说明应用为何呈现另一配置。** 应用段明确精简单发射、Cache关闭、CPU/NPU 50 MHz，再说明NPU承担主要卷积。100 MHz的CPU性能板测和50 MHz的人脸检测从文字、字幕、镜头均分开。
4. **NPU突出任务分工与算子支持。** 保留YuNet、8位定点、普通/深度卷积、CPU解码/NMS；“三帧槽管理原图与结果”改成可听懂的结果与原画面匹配，三帧槽及帧号保留在局部示意。
5. **验证段压缩为三层。** 指令集/模块仿真、实板测试、片上逻辑分析。ModelSim与Fabric Debugger分别标注，不再口播三个CoreMark热点算法的名字。
6. **实拍增加到40秒。** 明确连接、入画、移动、无脸和持续更新五个时间窗口，保留真实等待，全部动态素材标为待拍摄。
7. **结尾集中成果。** 用CPU设计和板测、人脸检测功能验证、可复现材料收束；LUT/FF/APM和时序数值退出结尾画面，仍保留在技术依据中。
